# PDFjig 0.2.0

**暗号化の版。** 書き出すときにパスワードで保護を掛けられるようになり、
**パスワード付きの文書も開いたあとに編集して書き出せる**ようになった。
開くのにパスワードが要る文書の保護が引き継がれないときは、**書き出す前に**そう訊く。

**v0.1.2 以前を使っている場合は入れ替えること。** 自動更新の仕組みは無い。
**あの版には、失って困るものに届く経路が 2 つあった**——
**共有フォルダでは、出力先のフォルダの外を消させられた**こと、
**保存の直後に電源が落ちると、新旧どちらも失いうる**ことである。どちらもこの版で直してある。

---

## この版で入ったもの

### パスワードで保護して書き出す

**「ツール」→「パスワードで保護して保存…」。** 並べ替えや削除をした結果を、保護を掛けて 1 つのファイルに書き出す。

- **パスワードは 2 種類ある。** ユーザーパスワードは**開くのに要る**。オーナーパスワードは**権限を変えるのに要る**。
  どちらも確認のためにもう一度打つ——**打ち間違えると、開けない文書ができあがる**
- **権限は 3 つの束から選ぶ**（「印刷を許可」「テキスト抽出を許可」「編集を許可」）。
  8 つの項目を 1 つずつ選ぶこともできる
- **暗号方式の既定は AES-256 である。** 古い閲覧ソフト向けに AES-128 と RC4 も選べる。**RC4-40 は短時間で破られる**
- ★ **保護を掛ける前の中身が、ディスクに一度も落ちない。** 組み立てと保護を 1 回の書き出しで済ませる

★★ **オーナーパスワードだけを掛けた文書は、誰でも開ける。** 印刷やコピーを禁じる権限は、
**閲覧ソフトが自主的に従っているだけ**であり、従わないソフトでは効かない。
その設定にしようとすると、窓がそう伝える。**確実に守るなら、ユーザーパスワードを掛けること。**

★★ **権限を効かせるには、オーナーパスワードをユーザーパスワードと別に掛けること。**
オーナーパスワードを空にするか同じにすると、**文書を開けた人は権限も変えられる**。
そうなれば印刷やコピーの制限に意味が無く、窓もそう伝える。

★ **開いているファイルそのものへ保護を掛けて上書きすると、そのあとの編集は開き直すまで止まる**
（状態行に「開き直してください」と出る）。書き出したファイルを開き直すには、いま掛けたパスワードが要るためである。

### パスワード付きの文書を編集して書き出す

**開いたあとも、並べ替え・削除・回転・追加・分割・保存ができる**（v0.1.2 では開けるだけだった）。

★ **書き出すたびに、元の文書のパスワードをもう一度訊く。** 開いている間、パスワードを手元に持ち続けないためである。

★ **置き換えに失敗しても、保護されていない中身を作業場所に残さない。** 消し損ねたときは、その在り処を窓で伝える。

### 保護が引き継がれないことを、書き出す前に訊く

**開くのにパスワードが要る文書のページを含めて、保護を掛けずに書き出すと、出力は誰でも開ける。**
そのときは**保存先を選ぶより前に**そう伝え、**「中止」か「保護を外して書き出す…」**を選ばせる。**既定は「中止」である。**
中止すれば、保存先もパスワードも訊かれずに終わる。

- **元の保護をそのまま引き継ぐ道は無い。** 守りたいなら「パスワードで保護して保存」で掛け直す
- 保護を掛けても**ユーザーパスワードを空にした**なら、同じように訊く——出力は誰でも開ける
  （ボタンは「このまま書き出す…」）
- ★ **オーナーパスワードだけが掛かった文書**（開くのにパスワードが要らないもの）は**訊かない。**
  その権限の制限は引き継がれず、**書き出した後に警告で伝える**
- 分割は、できるファイルの数によらず **1 回だけ**訊く
- 保護された文書を**足しただけで、そのページを全部消していれば**訊かない。出力に入らないからである。
  ★ **ただしその文書のパスワードは、書き出すたびに訊く**

### 閉じる前に、保存していない編集を訊く

**「終了」「閉じる」「別の PDF を開く」のどれでも、閉じたら消える編集があれば訊く**（以前は黙って捨てていた）。
並べ替え・回転・削除・区切り・ファイルの追加や取り外しのうち、**実際に変えたものだけ**を挙げる。

- **既定は「キャンセル」である。** Enter を続けて押しても捨てない
- **元の PDF は変わらない。** 失うのは画面の上の編集だけである
- 書き出しの最中に終了を押したときは、書き終わってから確かめる。**書き出しで消えるものが無くなっていれば、訊かずに閉じる**
- ★ **区切りは保存では書かれない。** 区切りに従って分割するまでは、保存した後でも「消えるもの」に数える

### ファイルを外す操作に、キーボードから届く

**「ツール」→「ファイルを外す」に、開いているファイルが並ぶ。** 一覧の「×」と同じ確認を通る。
★ **外す確認の既定を「キャンセル」にした**——**v0.1.2 では Enter を続けて押すと外れた。** 唯一取り消せない操作である。

### 前の保存が途中で終わったときの控えを知らせる

**電源断や強制終了で保存が途中で終わると、元のファイルが作業場所（`.pdfjig-` で始まるフォルダ）に残ることがある。**
**次に同じフォルダへ保存したとき、保存が済んだ後に、その在り処を全部並べて伝える。** 消すまで毎回出る。

### 在り処のフォルダを写せる

**控えや消し損ねたファイルの在り処を出す窓に「フォルダの場所をコピー」を付けた。**
作業場所の名前は乱数なので、**書き写すと 1 桁の違いで辿り着けない。** 写すのはファイルではなく、それが入っているフォルダである。

### 同じ名前のファイルを区別する

**同じ名前のファイルを 2 つ開くと、区別が付くところまで親フォルダを添えて出す**（`report.pdf（work）`）。
一覧・「ファイルを外す」・外す確認・保護を訊く窓・パスワードを訊く窓のどれでも同じである。**ふだんの表示は変えない。**

## この版で直したこと

### ★★ 共有フォルダでは、出力先のフォルダの外を消させられた

**保存のたびに、前回の残りの作業場所を片づけている。** その片づけが、作業場所の中に置かれた
**ディレクトリジャンクションを辿り、その先を消していた。**
**出力先のフォルダに書ける人**がジャンクションを仕込んでおけば、**次の保存で必ずそこが消える。**

★ **共有フォルダ・ネットワークドライブ・他の利用者も書ける場所へ保存しているなら、この版へ入れ替えること。**
**自分だけが書けるフォルダなら実害は無い。**

**片づけは、pdfjig が作る 3 つの名前（`output.pdf` ／ `replaced.pdf` ／ `held`）だけを消す形にした。** 中を辿らない。
★ **確かめてから消すまでの間に作業場所そのものを差し替えられると、差し替えた先にある
その 3 つの名前のファイルは消えうる。** 名前を選べないので、ほかのファイルには届かない。

### ★ 保存の直後に電源が落ちると、新旧どちらも失いうる形だった

**書いた中身をディスクへ吐き出させないまま、元のファイルと入れ替えていた。**
入れ替えは先に確定しうるが、中身は遅れて書かれる。その間に電源が落ちると、
**元の名前には中身の無いファイルが残り、控えも既に消えている**おそれがあった。

**入れ替える前に、書いた中身がディスクへ届いたことを確かめる形にした。** 確かめられなかったときは「保存済み」にしない。

★ **実際に中身が失われるところは再現していない。** Windows の書き込みの順序からの読みである。

### 開けない理由を取り違えて伝えていた

**開けない理由が違えば、違うことを言う**ようにした。

- **フォルダ**を開こうとすると「PDF として読み取れません」と出ていた。いまは「入力ファイルを開けません」と出る
- **ほかのアプリが掴んでいるファイル**は「入力ファイルを開けません」と出ていた。いまは
  「ファイルを読み取れません。ほかのアプリで開いていないか……」と出る
- ★ **読み進めている途中で読めなくなったもの**（共有フォルダの切断など）は、**まだ**「PDF として読み取れません」になる

### タスクマネージャで名前が化けていた

**v0.1.0 から、タスクマネージャに `PDF ???…` と出ていた。** アプリ本体に埋め込む説明を日本語で渡しており、
ビルドの途中で `?` に置き換わっていた。**英語の説明にした。** アプリの動きには関係しない。

### ページの無い PDF を足すと、半端な状態が残った

**一覧には入っているのに並びには無い**状態になり、そのファイルは閉じられなかった。
**「このファイルにはページがありません。」と出して、何も変えない。**

## できること

| 操作 | 内容 |
|---|---|
| 開く | PDF を開いてサムネイル一覧を表示する。パスワード付きの文書も開ける |
| 並べ替え | サムネイルをドラッグして順序を入れ替える |
| 削除 | 選択したページを取り除く |
| 回転 | 右 / 左に 90 度回す |
| 範囲抽出 | 範囲を指定して、その範囲だけ残す |
| やり直し | 並び・向き・区切りを開いた直後の状態に戻す |
| 追加 | 開いている文書に他の PDF のページを足す。足したページはサムネイル上で一緒に並べ替えられる |
| 区切り | 新しいファイルの先頭にするページに印を付ける。枚数で機械的に入れることもできる |
| 分割 | 区切りに従って複数のファイルに分ける |
| 1 枚ずつ | 全ページを 1 ページずつのファイルに分ける。区切りは見ないし、消しもしない |
| 保存 | 並べ替え・削除・回転をまとめて 1 つのファイルに書き出す |
| **保護して保存** | **パスワードと権限を掛けて書き出す** |
| バージョン情報 | ヘルプメニューから版数・実行環境・AI の有無を確認する。不具合の報告に貼れる形でコピーできる。**更新の確認もここから** |

**パスワード付きの文書にも、上の操作がすべて使える。** 書き出すたびにパスワードを訊く。

並べ替え・削除・回転・追加はファイルを直接書き換えない。画面上の並びを変えるだけで、
「名前を付けて保存」で初めて書き出す。**勝手に上書きされることはない**——
★ **開いているファイルそのものを保存先に選べば置き換わる。**
そのときは Windows の保存ダイアログが「置き換えますか？」と訊く。

複数の PDF を 1 つに綴じるときは、1 つを開いてから「追加」で他を足す。足したページは
元からあったページと区別なく並べ替え・回転・削除でき、最後に一度だけ保存する。
どのページがどのファイルのものかは、一覧の色とサムネイルの帯で分かる。
間違えて足したファイルは、一覧の「×」か「ツール」→「ファイルを外す」で外せる。

逆に 1 つの文書を分けるときは、**新しいファイルの先頭にしたいページを選んで「区切り」を押す。**
サムネイルの左に縦線が出て、そこから次のファイルが始まる。印を付け終えてから「分割」を押す。
スキャンした束は書類ごとに枚数がまちまちなので、枚数で均等に割る方式では当たらない。
定型の綴りなら「N ページごとに区切る」で機械的に入れられる。
全部バラすだけなら「1 枚ずつ」で足りる。こちらは区切りを見ないので、付けた印はそのまま残る。

## この版に入っていないもの

以下は実装済みではない。README の機能表に挙がっていても、この版のアプリからは使えない。

- **しおり・文書情報・ページラベルの編集**（v0.3.0 予定）
- **表抽出**（v0.4.0 予定）
- **XLSX / CSV / JSON 出力**（v0.4.0 予定）
- **テキスト抽出の画面**（いまは `pdf-core` の API としてだけ動く。v0.4.0 予定）
- **AI 機能一式**（v0.5.0 以降）
- **コマンドラインツール**（配布物にはデスクトップアプリのみが入る）

以下は要望が来ても実装しない（設計上の線引き）。

PDF 本文のテキスト直接編集 / 電子署名 / フォーム作成 / PDF 生成・帳票出力 / 全文 RAG チャット

**上書きを避けるための小細工もしない。** 同名を見つけて `foo(1).pdf` のように連番を振ることも、
元のファイルを `.bak` に退避することもない。**どちらも「消えていないはず」という期待を作る割に、
どこに何が残ったのかが利用者から見えなくなる。** 上書きするかどうかは、その場で利用者が決める。

## 既知の制限

- **v0.1.2 の既知の制限に書いた「EXE を入れると、他の利用者の『アプリと機能』に `PDFjig` が並び、
  その人には消せない」は、確かめた範囲では起きていなかった。**
  アンインストール情報のキーはマシン単位の場所に作られるが（Windows Installer の登録の仕方である）、
  **ほかの利用者の「プログラムと機能」には並ばない**。管理者が入れた場合も、標準ユーザーが入れた場合も同じだった
  （Windows Sandbox で確かめた）。★ **設定アプリの「アプリ」一覧は見ていない**
- **上書きの扱いが「保存」と「分割」で違う。** どちらも上書きの判断は利用者のものだが、
  確認を取る場所が違う。
  - **「名前を付けて保存」は置き換える。** 既存のファイルを選ぶと、Windows の保存ダイアログが
    「置き換えますか？」と訊く。**確認を出すのはこのダイアログであり、pdfjig ではない。**
    「はい」と答えると置き換わる
  - **読み取り専用のファイルへは書き出さない。** 失敗として出て、元のファイルは属性も中身も変わらない
  - **分割は 1 つも書かずに失敗する。** 出力先に同名のファイルが 1 つでもあると、
    その時点で止まる。複数のファイルを一度に作る操作であり、
    どれが置き換わるのかを 1 つずつ確認させる形にはしていない
- ★ **アプリごと落ちたときは、その場では何も伝えられない。**
  **電源断・タスクの強制終了と、Windows のログオフ・シャットダウン**がそれに当たる。
  **閉じる前の確認もここは通らない。**
  - **次に同じフォルダへ保存したとき、控えの在り処を伝える**（上の「この版で入ったもの」）。
    ★ **分割では伝えない**——分割は作業場所を使わないので、見に行かない
  - **出力先が空で、同じフォルダに `.pdfjig-` で始まる作業場所が残っていたら、
    その中の `replaced.pdf` が元のファイルである。**
    **`output.pdf` は書きかけの新しいほうで、取り違えると保存前の内容を失う。**
    **消す前に開いて確かめること**
  - ★★ **パスワード付きの文書から、保護を掛けずに書き出していた場合、`output.pdf` は誰でも開ける。**
    要るものを取り出したら、**そのフォルダごと消すこと**
- ★ **書き出しの最中に「終了」を押すと、書き終わるまで待ってから閉じる。** その理由は状態行に出るが、
  **読み上げには届かない**
- **コード署名をしていない。** 初回起動時に Windows SmartScreen の警告が出る。
  「詳細情報」→「実行」で進める。下のチェックサムで取得したファイルを確かめられる

## 動作環境

- Windows 10 21H2 (x64) 以降 / Windows 11 (x64)
- Java の事前インストールは不要（ランタイムを同梱している）

## どれを取得すればよいか

| ファイル | 用途 |
|---|---|
| `PDFjig-0.2.0.exe` | **個人で使うならこれ。** ユーザー単位でインストールし、管理者権限が要らない |
| `PDFjig-0.2.0.msi` | 情報システム部門による一括配布向け。マシン単位で入り、管理者権限が要る |
| `PDFjig-0.2.0-win-x64.zip` | インストールせずに使う。展開して `PDFjig.exe` を直接実行する |

EXE と MSI は同じ製品であり、**両方を同時にインストールすることはできない。**
入れ替えるときは先に片方をアンインストールする。

`SHA256SUMS.txt` で取得したファイルのハッシュを確認できる。

```powershell
Get-FileHash .\PDFjig-0.2.0.exe -Algorithm SHA256
```

不具合は Issue へ。**脆弱性は公開の Issue に書かないこと**
（[セキュリティポリシー](https://github.com/propagandist/pdfjig/security/policy)）。
